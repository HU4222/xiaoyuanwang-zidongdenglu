# 1.0.6 更新说明

> 日期：2026-11-06 ｜ 基线 1.0.5 ｜ versionCode 7
>
> **一句话**：设置页的 LSPosed 卡片里多了一行「推荐应用」，点一下就把本机装的应用扫出来、按可能性排好，勾哪个填哪个，不用再对着几百个包名猜。

---

## 一、这次加了什么

### 1. 推荐应用扫描

位置：设置 → LSPosed 增强 → 目标应用包名 下方。

点「推荐应用 · 扫描本机已装应用」，会列出本机上跟校园网认证沾边的应用，按推荐度排序，每条显示「应用名（包名）」。勾选后点「填入」，包名自动写进上方输入框，多个用逗号分隔。

如果推荐区是空的，会自动退到全量列表；推荐区非空时，对话框底部也有「全部应用」可以切过去。

**这一步只负责填包名。填完之后仍要在 LSPosed 的作用域里勾上那个应用，模块才会生效** —— 这是 LSPosed 的机制，应用自己改不了。

### 2. 为什么不用 LSPosed 的静态「推荐作用域」

LSPosed 支持模块在 `AndroidManifest.xml` 里用 `xposedscope` 声明推荐作用域，管理器会直接显示。这条路没走，原因很具体：

那个声明要写**具体包名**的字符串数组。具体学校的客户端包名无法预先确认（每所学校都可能不同），写死一批猜测的包名，等于把「不知道」包装成「推荐」，勾错了要么不生效、要么把账号密码填进别的应用的输入框。所以这里改成运行时扫描本机真实安装情况 + 打分排序，结果可解释、可核对。

等你确认了具体包名，或者哪次诊断日志里带出了它，再补静态声明才有意义。

### 3. 打分规则

| 档位 | 分值 | 命中词 |
|---|---|---|
| 强 | 每个 +4 | `campus`、`ruijie`、`srun`、`drcom`、`netkeeper`、`eportal`、校园、锐捷、深澜、哆点、天翼校园、校园宽带 |
| 中 | 每个 +2 | `portal`、`netauth`、认证、网络接入、上网、拨号、宽带、`wlan` |
| 弱 | 每个 +1 | `wifi`、`wi-fi`、网络、`edu` |

包名和应用名都参与比对，大小写不敏感。**总分 ≥ 4 才进推荐区**。

刻意没把 `net` 放进弱词表：它会把 `com.tencent`、`com.netease` 这类包名全量命中，打分直接失效。

举例：`com.ruijie.wifiassistant` / 「锐捷Wi-Fi助手」= 10 分；`com.tencent.mm` / 「微信」= 0 分；「WiFi 分析仪」= 1 分，进不了推荐。

### 4. 包可见性

Android 11 起查不到没声明过的应用。这次只加了 `queries` 里的 `MAIN`/`LAUNCHER` 这一种 intent，没有申请 `QUERY_ALL_PACKAGES` 这种敏感权限：

- 校园网客户端一定有启动图标，这一条就够覆盖；
- 顺带把几百个系统组件挡在外面，列表不会变成垃圾场；
- LSPosed 管理器（`org.lsposed.manager` 及两个旧版包名）单独点名，保证查得到。

## 三、验证到哪一步

**自测 30 条全过**（`AppRankSelfTest`）：

- 10 个典型校园网客户端必须进推荐区：锐捷、深澜、Dr.COM 哆点、城市热点、天翼校园、NetKeeper、中文名、大小写混写；
- 6 个日常应用必须 0 分：微信、网易云音乐、淘宝、米家、高德、支付宝；
- 3 个通用词应用必须低分且进不了推荐：WiFi 分析仪、网络收音机、WLAN 工具；
- 空值 / null / 推荐线上下 / 显示格式 / 排序稳定性。

**APK 内容校验**：

```
versionCode=7  versionName=1.0.6
<queries> 已在 AndroidManifest.xml 中（line=31）
dex 内存在 Lcom/campusnet/autologin/core/AppRank; 与 AppScanner;
de/robv/android/xposed/* 未作为类定义进包（框架桩仍是 compileOnly，只留字符串引用）
模块自身 XposedEntry / AutoFiller / XLog 在包内
```

**没验的**：真机点开这个对话框的实际效果。手机没连上电脑，`adb devices` 是空的，这一段只能等装上之后自己点一下。

## 四、怎么用

1. 装 1.0.6（覆盖安装，配置和账号都保留）；
2. 设置 → LSPosed 增强 → 点「推荐应用 · 扫描本机已装应用」；
3. 勾上学校客户端，点「填入」；
4. 去 LSPosed 管理器 → 模块 → 校园网自动登录 → 作用域，勾上同一个应用；
5. 强停并重开那个客户端，进它的登录页，账号密码会被自动填好。

第 2 步如果推荐区没出现你那个应用，点对话框里的「全部应用」翻全量列表。
