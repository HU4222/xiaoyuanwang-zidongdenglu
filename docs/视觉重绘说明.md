## 3. 字号与组件

| 层级 | 规格 | 落地位置 |
|---|---|---|
| 页面主标题 | 24sp / 650 / -.02em | 主界面标题 |
| 二级页标题 | 20sp / 650 | 高级设置、运行日志 |
| 卡片标题 | 14sp / 650 | 自动重连 |
| 区块小标题 | 14sp / 650 / text-2 | 账号、守护、各设置分组 |
| 正文 | 15sp / 400 | 输入框、列表行标题 |
| 键值行 | 13sp，左灰右黑 | 认证方式 / 心跳间隔 / 上次结果 |
| 辅助说明 | 12–13sp / muted | 卡片脚注 |
| 标签 | 11sp / 500 | 状态徽章 |

卡片统一 18dp 圆角 + 16×18 内边距 + 1px 描边 + 2dp 阴影。描边和阴影**必须同时存在**，
只剩阴影会发飘，只剩描边会发平——这是规范里点名的。

图标全部手绘 vector（`ic_wifi` / `ic_shield` / `ic_sliders` / `ic_list` / `ic_back` / `ic_copy` / `ic_trash` / `ic_check`），
stroke 1.7、round cap/join，不引图标库，着色靠 `tint` 跟随文字色。

## 4. 三处判断，需要你知道

### 4.1 深色主按钮改用深底字

规范写「深色下 `--brand` 提亮到 `#8B87FF`」，也写「主按钮渐变 + 白字」。
两条同时满足时，白字压在 `#8B87FF` 上对比度只有约 **2:1**，属于读不清。

处理：深色下 `onBrand` 取 `#12162B`（深底字），对比度回到约 8:1。
亮色仍为白字。这是对未来规范的一个建议补充：**提亮主色时要同步考虑其上的前景色**。

### 4.2 页面左右留白取 18dp 而非 12px

DropLink 是 WebView 界面，规范写「页面左右留白（手机）12px」。
Android 侧参考《SpaceLens-PRD》第 8 节的落地值取 **18dp**——与卡片圆角 18 呼应，且 12dp 在
实体机上会让 18dp 圆角的卡片贴边显得局促。卡片内边距仍严格 16×18。

### 4.3 状态徽章取代了原来的「认证方式」文字

原界面右上角显示认证方式（如 Dr.COM），现在：
- 右上角胶囊 → **健康状态**（在线 / 离线 / 检测中 / 已停止），配色跟着语义走
- 卡片内新增 kv 行 → **认证方式**、**心跳间隔**、**上次结果**

信息没丢，但状态与配置分开了。原来把两者混在一处，最容易出现「点是绿的、文字写着离线」的自相矛盾。

## 5. 动效落地

| 名称 | 参数 | 用在哪 |
|---|---|---|
| `viewIn` | alpha 0→1、translateY 10dp→0、scale .995→1，280ms，`cubic-bezier(.22,.9,.3,1)` | 三个页面进入 |
| `ping` | scale .85→1.9、alpha .5→0，2400ms 无限，`cubic-bezier(0,0,.2,1)` | 状态点外圈 |
| `press` | scale .97，130ms | 主按钮按下 |

规范里的「反馈 ≤0.2s / 入场 ≤0.38s / 循环 ≥1.3s」三档都守住了，没有引入 spring / bounce 曲线。
按下只缩放、不位移、不变色。

### 总开关（重要）

所有动画统一读系统的 `ANIMATOR_DURATION_SCALE`。置 0 时：

- 页面直接落终态，不播入场
- 状态点只留一个静止圆点，外圈隐藏，动画不启动

原因写在动效规范第八节：`.status-dot` 的 ping 是无限循环，`uiautomator dump` 会等界面「静止」
才返回，DropLink 项目实测连续 4 次超时。所以这次直接把开关做进代码，而不是等踩坑再改。

```bash
adb shell settings put global animator_duration_scale 0   # 关
adb shell settings put global animator_duration_scale 1   # 恢复
```

## 6. 验证到哪一步

已验证：

- `assembleRelease` 通过，APK 签名有效
- `values-night` 资源确实打进包（`aapt2 dump resources` 里 `color/bg` 有 `()` 和 `(night)` 两份）
- Xposed 桩类仍未被打进 APK（dexdump 查 `de/robv/android/xposed` 为空）
- 旧布局里的所有控件 id 全部保留，`SettingsActivity` 不需要改

没有验证：

- **运行时渲染**。这台机器没有 Android 模拟器（无 emulator / 无 AVD / 无系统镜像），手机也没连，
  所以没能截图取证。布局是按规范和尺寸推算的，实机上可能有个别间距需要微调。

装上后请重点看第 13、14 项校验（深浅色外观、动效开关），那是这次改动最直接的可观测面。
